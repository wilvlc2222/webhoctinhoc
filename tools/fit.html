Dev tool. Opens each lesson at 1300x700 and reports every step: +N = overflows by N px, ok-N = N px still free. First line = fresh page with all reveals open. Second line (with &solve=1) = after the tool plays every activity, so all feedback lines are showing; it also reports the stars earned. It uses a separate learner name and deletes it afterwards. Usage: tools/fit.html?pages=lop4/bai02.html,lop4/bai03.html&solve=1
